
# Used Car Price Prediction

## Project Overview
This project predicts used car prices using Linear Regression.

## Dataset
The dataset contains used car information, including brand, model, age, mileage, transmission, and fuel type.

## Project Steps
1. Data loading using Pandas.
2. Data cleaning and preprocessing.
3. Exploratory Data Analysis (EDA).
4. Train-test split.
5. Linear Regression model training and prediction.
6. Model evaluation using MAE, MSE, RMSE, and R2 Score.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
